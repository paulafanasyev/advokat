# Адвокат Негнюров Иван Юрьевич

Сайт: https://paulafanasyev.github.io/advokat/

Весь сайт в одном файле `index.html`. Публикация автоматическая при каждом изменении в `main` (`.github/workflows/pages.yml`).

## Помощник записи

Кнопка «Помощник и запись» (на телефоне «Записаться» в нижней панели). Помощник спрашивает ситуацию, даёт первые шаги и записывает: формат, день, время, имя, телефон, комментарий. Заявка уходит письмом на Negnyurov@mail.ru через FormSubmit.

**Активация (один раз):** отправьте с сайта тестовую заявку, откройте письмо от FormSubmit на Negnyurov@mail.ru и нажмите Activate. Проверьте спам.

Если сервис недоступен, сайт предлагает отправить заявку через почтовую программу или позвонить. Адрес отправки: строка `endpoint:` в объекте `CFG` в index.html.

FormSubmit работает за рубежом (трансграничная передача персональных данных, 152-ФЗ); это указано в политике на сайте.
